# FriendyChat Signaling Server

Ce projet est le serveur de signalisation de FriendyChat.

## Fonctionnalités

- Appels audio
- Appels vidéo
- Signalisation WebRTC
- Socket.IO
- Gestion des utilisateurs connectés
- Notifications d'appels

## Installation

```bash
npm install
npm start
```

Le serveur démarre automatiquement sur le port défini par Render ou sur le port 3000 en local.

## Technologies

- Node.js
- Express
- Socket.IO
- WebRTC
